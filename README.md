# Connect 4

Reagan's Connect 4 game, live at [connect4.rwillard.com](https://connect4.rwillard.com).

## How to deploy

Open Terminal, go to this folder, and run:

```
npm run deploy
```

That's it! Your changes will be live at connect4.rwillard.com in about a minute.

## How to run locally

To test changes on your computer before deploying:

```
npm start
```

Then open your browser and go to `http://localhost:3000`.
